# Copy Post

Плагин WordPress Multisite для копирования записей и страниц между сайтами сети.

## Возможности

- Копирование записей, страниц и включённых публичных типов записей с текущего сайта сети на другие сайты.
- Перенос таксономий, произвольных полей, миниатюры и медиа из контента/меты, комментариев (опционально).
- Выбор таксономий отдельно для каждого целевого сайта: копировать с источника, выбрать существующие термины на цели или не копировать; создание новых терминов прямо в окне копирования.
- Перепривязка ID вложений в блоках Gutenberg, галереях, классическом HTML и shortcode.
- Переписывание ссылок исходного сайта и URL медиа.
- Связь «источник ↔ копия», обновление существующей копии, защита от случайных дублей.
- Копирование из списка записей, массовое действие и отдельная страница «Инструменты → Копирование записей».
- WP-CLI: `wp copy-post`.
- Обновления из GitHub Releases.

## Требования

- WordPress 6.1+.
- WordPress Multisite (плагин активируется по сети).
- PHP 7.4+.

## Установка

1. Соберите архив:
   ```powershell
   powershell -ExecutionPolicy Bypass -File tools/build-release.ps1
   ```
2. Установите `dist/copy-post-<version>.zip` в сеть.
3. Активируйте плагин для всей сети.
4. Настройте параметры в **Сеть → Настройки → Копирование записей**.

## Разработка

Плагин не требует Composer, npm или сборки JS. Файлы подключаются автозагрузчиком из `includes/`.

Проверка синтаксиса:

```powershell
Get-ChildItem -Recurse -Filter *.php | ForEach-Object { php -l $_.FullName }
node --check assets/js/admin.js
```

## CLI

```bash
wp copy-post sites
wp copy-post posts --site=2 --post-type=post
wp copy-post copy 123 --to=2 --status=draft
wp copy-post copy 123 --to=2,3 --duplicate=update
wp copy-post copy 123 --to=2 --skip-media
```

## Хуки

- `copy_post_payload` — данные записи перед вставкой.
- `copy_post_content` — контент после перепривязки.
- `copy_post_meta_value` — значение мета-поля.
- `copy_post_before_insert` — действие перед вставкой.
- `copy_post_after` — действие после копирования.
- `copy_post_sites_limit` — лимит сайтов в списке.
- `copy_post_target_content_url` — базовый URL uploads целевого сайта.

## Ограничения

- Нет двусторонней синхронизации: только ручное копирование/обновление из источника.
- Page builders, ACF-связи и нестандартные shortcode могут требовать собственных фильтров.
- Комментарии синхронизируются только при создании копии.
- Меню, виджеты, настройки и произвольные таблицы не копируются.
